# Change Log

All notable changes to the "moody-dark-themes" extension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.0.4] - 2026-11-11

### Added
- **Moody Dark Forest**: New botanical, pine-black theme featuring sage emerald, frost cyan, and warm barley gold accents.
- High-resolution screenshot previews for Moody Dark, Moody Dark Charcoal, and Moody Dark Forest in `README.md`.
- Comprehensive semantic token highlighting (`semanticTokenColors`) across all themes for enhanced TypeScript, Python, Rust, and Go code clarity (italicized parameters, distinct readonly constants, type parameters, and standard globals).
- Dedicated syntax highlighting rules for HTML/JSX attributes and JSON/YAML property keys.

### Changed
- Refined bracket pair colorization with a balanced 4-color low-contrast pastel cycle across all themes.
- Aligned git additions, diff backgrounds, and gutter markers in Moody Dark to a calm, cohesive sage green (`#8EB69B`).
- Updated documentation and installation instructions to cover all three theme options.

### Fixed
- Fixed terminal ANSI green colors in Moody Dark (replaced warning-like orange with proper muted sage green `#8EB69B` / `#A8CEB3`).

## [0.0.3] - 2026-11-10

### Added
- **Moody Dark Charcoal**: Softer charcoal theme with warm stone tones and muted blue accents.

### Changed
- Improved package metadata and extension asset paths.

## [0.0.2] - 2026-11-10

### Added
- Automated Open VSX publishing workflow.
- Continuous deployment configuration with Node 22 and trusted publishing.

## [0.0.1] - 2026-11-10

### Added
- Initial release featuring the **Moody Dark** theme.
- Support for syntax highlighting and VS Code workbench UI styling.
